# LAOS REMIX

เว็บแจกเพลงพร้อมเซิร์ฟเวอร์บันทึกไฟล์และข้อมูลเพลงในเครื่อง

## เปิดใช้งาน

ติดตั้ง Node.js แล้วเปิด Terminal ในโฟลเดอร์โปรเจกต์ จากนั้นรัน:

```sh
npm start
```

เปิดเว็บที่ <http://localhost:3000> (ต้องเปิดผ่าน URL นี้ ไม่ใช่เปิด `index.html` โดยตรง)

ไฟล์เพลงที่อัปโหลดจะถูกแยกเก็บใน `uploads/` และข้อมูลชื่อเพลง/ศิลปิน/หมวดหมู่จะเก็บใน `data/tracks.json` ทั้งสองส่วนอยู่ในโฟลเดอร์โปรเจกต์ ไฟล์ขนาดสูงสุด 50 MB ต่อเพลง

เซิร์ฟเวอร์นี้เก็บข้อมูลในเครื่องที่กำลังรันอยู่ หากต้องการให้คนอื่นเข้าเว็บและอัปโหลดจากอินเทอร์เน็ต ต้องนำโฟลเดอร์นี้ไปติดตั้งบนโฮสต์ที่มีพื้นที่เก็บไฟล์ถาวร
